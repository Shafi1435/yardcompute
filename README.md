# YardCompute

Free calculators for home and yard projects.

## Included
- Fence Calculator
- Fence Post Spacing Calculator
- Fence Post Concrete Calculator
- Deck Board Calculator
- Deck Board Spacing Calculator
- Concrete Calculator
- Post Hole Concrete Calculator
- Gravel Calculator
- Driveway Gravel Calculator
- Mulch Calculator

Static, dependency-light site designed for Cloudflare Workers Static Assets.

## Routing
Calculator folders use trailing-slash URLs and are served from their `index.html` files by the Workers Static Assets configuration.

## Local preview
npm install
npm run preview

## Deploy
npm run deploy
