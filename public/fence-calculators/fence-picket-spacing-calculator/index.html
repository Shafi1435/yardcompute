How to space fence pickets evenly

This fence picket spacing calculator estimates how many pickets fit along a straight fence run and the resulting gap when pickets are spread evenly. It uses the fence length, actual picket face width, and maximum gap you want between adjacent pickets. It is designed for layout planning, not for calculating fence post spacing or gate hardware.

Formula for picket count and adjusted gap

Convert the fence run from feet to inches before comparing it with picket width and gap.

Fence run in inches = fence length in feet × 12

The calculator estimates the number of pickets using the maximum permitted gap:

Pickets = ceiling((fence run in inches + maximum gap) ÷ (picket width + maximum gap))

It then calculates the even gap for the chosen picket count:

Adjusted gap = (fence run in inches − picket count × picket width) ÷ (picket count − 1)

The adjusted gap assumes the run is filled by the pickets and the gaps between adjacent pickets. Real installations may also have end margins or different edge spacing, so check the layout against the actual fence boards and rails before fastening.

Worked example: 100-foot fence with 5.5-inch pickets

Suppose a straight run is 100 feet long, each picket is 5.5 inches wide, and the maximum desired gap is 2 inches.

  1. Convert the run: 100 × 12 = 1,200 inches.
  2. Calculate picket count: ceiling((1,200 + 2) ÷ (5.5 + 2)) = ceiling(160.27) = 161 pickets.
  3. Calculate the adjusted gap: (1,200 − 161 × 5.5) ÷ (161 − 1) = 1.966 inches (approximately).

This estimate keeps the calculated gap below the 2-inch maximum. The final count may change if your layout includes end gaps, posts, gates, board overlaps, or cut pickets.

How to measure accurately

  1. Measure the clear length that will actually receive pickets; do not automatically include gate openings or sections that will not be boarded.
  2. Measure the actual picket face width, not the nominal lumber size printed on a product listing.
  3. Choose a maximum gap that suits your fence design and any applicable pool, pet-containment, privacy, or local requirements.
  4. Run the calculation, then mark a short test section to confirm the pickets and gaps fit as expected.
  5. Repeat separately for fence runs with different lengths, picket widths, or spacing requirements.

Adjusted gap versus maximum gap

The maximum gap is the limit you enter. The adjusted gap is the calculated even spacing after the picket count is rounded to a whole number. These values may differ because a fence run rarely divides perfectly into the exact picket-plus-gap width. Check that the adjusted gap is acceptable for your fence purpose and local rules.

Common layout mistakes

  • Using nominal rather than actual picket width.
  • Measuring the whole property boundary instead of the boardable fence run.
  • Forgetting to exclude gates or openings.
  • Assuming edge gaps are automatically handled the same way as gaps between pickets.
  • Confusing picket gaps with the distance between fence posts.
  • Using a generic gap without checking product instructions or local safety requirements.

Frequently asked questions

How many pickets do I need for a 100-foot fence?

The count depends on actual picket width and the maximum gap. With 5.5-inch pickets and a 2-inch maximum gap, this calculator estimates 161 pickets across a 100-foot straight run before considering edge margins, cuts, or damaged boards.

What is a good gap between fence pickets?

There is no single gap for every fence. Consider the fence style, privacy needs, pet containment, board dimensions, product instructions, and applicable local requirements. For regulated barriers such as pool fences, follow the relevant code rather than a generic estimate.

Why is the adjusted gap different from my input?

The calculator must use a whole number of pickets. It chooses a count based on your maximum gap and calculates an even gap for that count, so the resulting gap may be smaller than the maximum you entered.

Does this include gaps at both ends?

The calculation models the spaces between adjacent pickets and does not separately allocate custom margins at the ends. If your fence design requires end margins, mark the usable length and verify a sample layout before installing all boards.

Does this calculate fence post spacing?

No. Picket spacing is the gap between boards; post spacing is the distance between fence posts. Use the Fence Post Spacing Calculator for post layout.

Should I order extra pickets?

Consider extra material for cuts, defects, and future repairs. This calculator estimates the layout count but does not add a waste allowance, so choose an order quantity based on your cutting plan and supplier packaging.

Can I use different picket widths?

Yes. Enter the actual face width for the product you intend to install. Recalculate when the board width or maximum gap changes.
