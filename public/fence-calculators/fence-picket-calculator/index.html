How many fence pickets do I need?

The number of pickets depends on three things: how long the fence is, how wide each picket really is, and how much gap you leave between them. This calculator converts the fence length to inches, divides it by the width of one picket plus one gap, rounds up to a whole picket, and then adds your waste allowance.

How to use the fence picket calculator

  1. Enter the total length of fence that will get pickets. Leave out gate openings unless the gate will use the same pickets.
  2. Enter the actual picket width. A board sold as a 1×6 picket is usually about 5.5 in wide, not 6 in.
  3. Enter the gap between pickets. Use 0 for a tight privacy fence, a small gap for shrinkage, or a wider gap for a spaced picket look.
  4. Set a waste allowance and select Calculate.

Formula

Pickets without waste = round up ((fence length × 12) ÷ (picket width + gap))
Pickets to order = round up (pickets without waste × (1 + waste % ÷ 100))

Example

The default values describe a 100 ft fence with 5.5 in pickets and a 1/8 in (0.125 in) gap. 100 ft is 1,200 in, and each picket plus gap takes up 5.625 in. 1,200 ÷ 5.625 = 213.3, which rounds up to 214 pickets. With 10% extra, the calculator suggests 236 pickets.

If you butt the same pickets tight with no gap, 1,200 ÷ 5.5 = 218.2, so you need 219 pickets before waste. That is 5 more pickets than the gapped layout.

Why the gap matters

Even a small gap adds up over a long fence. Wood pickets can also shrink as they dry, so a fence installed tight may open up small gaps later. For a fence that stays fully private, some builders overlap pickets or use a board-on-board layout. Those designs need more pickets than this simple single-layer formula gives.

Common planning mistakes

  • Using the nominal width (6 in) instead of the actual width (about 5.5 in), which undercounts pickets.
  • Forgetting the second side of a shadowbox or board-on-board fence, where pickets alternate on both sides of the rails.
  • Ordering the exact count with nothing left for split ends, knots, or bad boards.
  • Including gate openings that will be built from different material.

Frequently asked questions

What waste allowance should I use?

A 5–10% allowance is a common starting point for a straight fence with decent lumber. Use more if you are cutting pickets for slopes or decorative tops, or if the lumber quality varies.

How do I count pickets for a board-on-board fence?

Treat it as two layers. Calculate each side with its own spacing, usually a gap a bit narrower than one picket, and add the two results together.

Does the fence height change the picket count?

No. Height changes the picket length you buy, not the number of pickets across the fence.

Can I use centimeters?

Yes. Switch the picket width and gap units to centimeters and the fence length to meters, and the calculator converts them for you.

Does this count rails or posts?

No. Use the Fence Rail Calculator and Fence Post Spacing Calculator for those parts, or the Fence Material Calculator for a combined estimate.
