What materials does a privacy fence need?

A basic wood privacy fence has four main parts: posts, the sections between posts, horizontal rails, and vertical pickets. This calculator estimates all of them for one straight run so you can build a first shopping list in one step.

How to use the privacy fence materials calculator

  1. Enter the total fence length in feet.
  2. Enter the post spacing. 8 ft or less is common for wood fences.
  3. Enter the rails per section. Many 6 ft privacy fences use three.
  4. Enter the actual picket width and gap. For a fully private fence, use a gap of 0.
  5. Set a waste allowance and select Calculate.

Formula

Sections = round up (fence length ÷ post spacing)
Posts = sections + 1
Rails to order = round up (sections × rails per section × (1 + waste % ÷ 100))
Pickets to order = round up ((fence length × 12) ÷ (picket width + gap) × (1 + waste % ÷ 100))

Example

The default values describe a 100 ft fence with posts every 8 ft, 3 rails per section, and 5.5 in pickets with 1/8 in gaps. That gives 13 sections and 14 posts. With 10% extra, you would order 43 rails and 235 pickets.

Posts on real fences

The post count assumes one straight run with a post at each end. Real fences often need more:

  • Each corner where the fence changes direction may start a new run.
  • Gates usually need two strong posts of their own, one on each side.
  • Where the fence meets a house or another fence, you may need an end post or a wall bracket instead.
  • Calculate each straight side separately and add the results for the most reliable count.

What else to buy

  • Concrete or gravel to set posts. Use the Fence Post Concrete Calculator.
  • Nails or screws for pickets and rails, and rail brackets if you use them.
  • Gate hardware: hinges, latch, and a drop rod for double gates.
  • Post caps, a top cap board, or trim if your design includes them.

Frequently asked questions

Why might the picket count differ slightly from the Fence Picket Calculator?

This calculator applies the waste allowance before rounding, while the picket calculator rounds first and then adds waste. The difference is usually one picket.

Can I use this for a board-on-board fence?

Not directly. Board-on-board fences need pickets on both layers. Calculate each layer with the Fence Picket Calculator.

Should I subtract gate openings?

Yes, if gates are built from different material. Subtract the gate width from the fence length and use the Fence Gate Calculator for the gate.

Can I use metric measurements?

Yes. Switch the lengths to meters and picket width and gap to centimeters.

Do I need a permit for a privacy fence?

Many areas limit fence height and location, and some require a permit or HOA approval. Check before you build.
