What materials do I need for a deck?

This calculator gives a first-pass shopping list for the two biggest parts of a simple rectangular deck: the decking boards on top and the joists underneath. It counts boards across the deck width, counts joists at your spacing, and turns both into linear feet with a waste allowance.

How to use the deck materials calculator

  1. Enter the deck length as the direction the decking boards run, and the deck width as the direction they are laid across. The joists run the other way, under the boards.
  2. Enter the actual board width and gap between boards.
  3. Enter the joist spacing on center.
  4. Set a waste allowance and select Calculate.

Formula

Boards = round up ((width × 12 + gap) ÷ (board width + gap))
Boards to order = round up (boards × (1 + waste % ÷ 100))
Deck board linear feet = boards × length × (1 + waste % ÷ 100)
Joists = round up ((length × 12) ÷ joist spacing) + 1
Joist linear feet = joists × width × (1 + waste % ÷ 100)

Example

The default values describe a 16 ft × 12 ft deck with 5.5 in boards, 1/8 in gaps, and joists at 16 in on center. The 12 ft width takes 26 boards, or 29 boards with 10% extra, which is 457.6 linear feet of decking. The joists run across the boards, so they are spaced along the 16 ft length: 192 ÷ 16 = 12 spaces, or 13 joists. Each joist spans the 12 ft width, so that is 156 linear feet, or 171.6 linear feet with 10% extra. The deck area is 192 sq ft.

How the boards and joists fit together

Decking boards run in one direction and the joists run at a right angle underneath them. In this calculator the boards run along the deck length, so the joists are spaced along the length and each joist spans the deck width. If your deck plan turns the boards the other way, swap the length and width. The Deck Board Calculator and Deck Joist Calculator give more detail for each part.

What is not on this list

  • Beams, posts, ledger board, rim joists, and blocking.
  • Footings. Use the Deck Footing Calculator.
  • Deck screws or hidden fasteners. Use the Deck Screw Calculator.
  • Joist hangers, post bases, flashing, and other connectors.
  • Stairs, railings, and fascia boards.

Frequently asked questions

Why did the joist count change from earlier versions of this page?

Earlier versions spaced joists across the width, as if they ran the same way as the boards. The calculator now spaces joists at right angles to the decking, which matches how decks are built.

What waste allowance should I use?

A 5–10% allowance is a common starting point for a straight-laid rectangle. Diagonal decking, picture-frame borders, and many cuts call for more.

Do I buy boards in the exact deck length?

Lumber comes in standard lengths. Round up to the next available length, or plan joints that fall over joists.

Does it work for composite decking?

Yes for planning. Use the actual board width and the gap and joist spacing required by the composite manufacturer.

Can I enter metric sizes?

Yes. Switch deck dimensions to meters and board width, gap, and spacing to centimeters.
