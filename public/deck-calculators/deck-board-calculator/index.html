How the deck board calculator works

Enter deck length and width, board width, and the planned board gap. The calculator estimates how many boards are needed across the deck width.

Formula

Board coverage width = board width + gap
Boards = floor((deck width + gap) ÷ (board width + gap))

Example

For a 16 ft wide deck using 5.5 inch boards with a 1/8 inch gap, the calculator estimates 34 boards across the 16 ft width.

Assumptions and material notes

The current estimate assumes boards run across the deck length and uses whole-board counts. It does not optimize staggered joints, picture framing, diagonal layouts, or board-specific overhangs. Buy extra material for cuts and defects.

Frequently asked questions

Does this calculate board lengths?

It uses the entered deck length as the estimated board length. It does not add overhang or optimize board lengths for cuts.

Should I add waste?

Yes, especially for angled cuts, staggered joints, picture framing, and defects.

What gap should I use?

Use the gap recommended by the decking manufacturer and local installation guidance.

Can I use decimal board widths?

Yes.
