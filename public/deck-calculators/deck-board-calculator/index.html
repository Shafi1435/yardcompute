How many deck boards do I need?

Use the calculator to estimate the number of boards needed to cover the deck width. Enter the deck dimensions, the actual board width, and the planned gap between boards. The calculator uses whole boards and reports base linear footage before project-specific waste.

How to use the deck board calculator

  1. Measure the deck length and width.
  2. Enter the actual board width, not the nominal lumber size.
  3. Enter the installation gap recommended by the decking manufacturer.
  4. Review the board count and base linear feet.
  5. Add extra material for cuts, defects, picture framing, diagonal layouts, and other project-specific waste.

Formula

Board pitch = board width + gap
Boards = ceiling((deck width + gap) ÷ (board width + gap))
Base linear feet = boards × board run length

Example

Suppose a deck is 16 ft wide and each board is 5.5 inches wide with a 1/8-inch gap. The calculator estimates 35 boards across the width. If each board runs 12 ft, the base requirement is 420 linear feet before waste and cutting allowances.

Board width and spacing matter

Deck boards are commonly sold by nominal sizes such as 2×6, but the actual finished width is smaller. Use the measured or manufacturer-listed actual width when possible. Spacing also changes the number of rows, so use the gap required for your decking material and installation conditions rather than assuming one universal gap.

Common planning mistakes

  • Using nominal board width instead of actual width.
  • Forgetting that angled layouts and picture framing create additional cuts.
  • Ordering only the mathematical minimum with no allowance for defects.
  • Assuming every deck can be covered efficiently with one stock board length.
  • Ignoring manufacturer installation instructions for spacing and fastening.

Frequently asked questions

Does this calculate board lengths?

It uses the entered deck length as the estimated board run length. It does not optimize stock-board lengths, overhangs, butt joints, or cutting patterns.

Should I add waste?

Yes. Add extra material for cuts, defects, diagonal or angled layouts, picture framing, and other project-specific losses.

What gap should I use?

Use the gap recommended by the decking manufacturer and applicable installation guidance. Moisture, board type, and installation conditions can affect the appropriate gap.

Can I use decimal board widths?

Yes. Enter the actual board width in inches; decimal values are supported.

Does the calculator include waste?

No. The board count and linear footage are base estimates. Add your own waste allowance based on the project layout.

Does deck shape affect the result?

Yes. This calculator is designed for a basic rectangular deck. L-shapes, curves, stairs, borders, and complex layouts need additional measurements.

Can I use composite decking?

Yes for planning, but use the actual board width and manufacturer-required gap for the specific product.

Should I verify the result before buying?

Yes. Confirm board dimensions, available stock lengths, installation pattern, waste, and manufacturer requirements with your supplier or installer.
